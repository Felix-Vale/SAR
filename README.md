# SAR

## Model Weights

The pretrained model weights (`.pt` files) are available on Google Drive:

**[Download Model Weights (.pt)](https://drive.google.com/drive/folders/1gdL9AKHtytDZ7nKY68EFCSGQM78Z8HP2)**

Please download the required `.pt` files from the link above and place them in the corresponding checkpoint directory before running inference or evaluation.


## Usage

After downloading the model weights, you can specify the path to the `.pt` checkpoint when running the evaluation or inference script.
